# Dental clinic landing page

A responsive, static clinic website. Open `index.html` directly or serve this folder with any static web server. Clinic details are read from query parameters:

`?doctor=Dr.%20Maya%20Shah&clinic=Bright%20Smiles&phone=%2B919876543210&email=hello%40brightsmiles.in&address=12%20Park%20Road%2C%20Mumbai&patients=1200%2B&experience=8%2B&certifications=3`

Supported parameters: `doctor`, `clinic`, `phone`, `email`, `address`, `patients`, `experience`, and `certifications`. The last three populate the mobile-only hero trust strip; replace their demo defaults with verified clinic figures before publishing. Omitted values use the SmileCare demo defaults. Include the country code in `phone` for WhatsApp (for example, `+919876543210`). The booking form asks only for the patient's name and service, then opens WhatsApp with a prefilled message. The service and smile gallery photos are illustrative generated imagery; replace the gallery with the clinic's real patient photos before presenting results as actual cases.
